Support

Loop je ergens tegenaan in Platefull? Mail ons op support@linkandlead.nl. We reageren meestal binnen twee werkdagen.

Veelgestelde vragen

Ik krijg geen inlogcode

Kijk in je map met ongewenste e-mail. De code is 15 minuten geldig. Vraag anders een nieuwe code aan; de vorige vervalt dan.

Waarom zie ik maar een paar gerechten?

Heeft iemand in je gezin een allergie, dan stelt Platefull alleen gerechten voor waarvan alle ingrediënten zeker passen. Producten waarvan de samenstelling per merk verschilt (zoals wraps, sauzen en kaas) worden pas gebruikt als je het etiket hebt gecontroleerd via Instellingen → Etiketcontroles.

Hoe nodig ik mijn partner uit?

Ga naar Instellingen → Tweede volwassene uitnodigen, vul het e-mailadres in en deel de uitnodiging. Die is 7 dagen geldig en werkt alleen voor dat e-mailadres.

Hoe verwijder ik mijn gegevens?

Via Instellingen → Verwijderen. Je kunt je eigen account of het hele gezin verwijderen. Lees in de privacyverklaring wat er dan precies gebeurt.

Belangrijk

Platefull is geen medisch hulpmiddel. Controleer bij een allergie altijd zelf het etiket van wat je koopt.
